# Can Line Performance Analytics

End-to-end operations analytics for an aluminium beverage-can plant: **OEE**, **downtime Pareto**, **crew comparison**, **SPC (X-bar/R) with Western Electric rules**, **process capability (Cpk)** and an automated **daily operations meeting pack** in Excel.

> All data is synthetic and generated by `src/generate_data.py`. It contains deliberately planted problems so the analysis can show how each one is detected.

## Business question

A plant runs two can lines on three shifts with four rotating crews. The operations team meets every morning and needs to know:

1. Are we hitting the OEE target, and where are we losing time?
2. Is a loss caused by the machine or by the way it is run?
3. Is any critical quality characteristic drifting **before** it goes out of spec?
4. What should go on the action list (PDCA) today?

## Results

| Finding | Evidence | Recommended action |
|---|---|---|
| Line 2 OEE is **78.8%**, 1.2 pts below the 80% target | OEE = Availability x Performance x Quality, aggregated from shift data | Focus on availability losses |
| Line 2 decorator stops are **crew-specific**: Crew C averages ~52 min/shift vs ~9 min for other crews | Mann-Whitney U test, p < 0.001; Crew C OEE 72.9% vs 79.7-82.3% | Gemba with Crew C, review ink/blanket change SOP and training |
| Line 1 changeovers doubled in count and got **~70% longer** in the second half of the period (~38 extra hours) | Before/after comparison, p = 0.001 | SMED study |
| Line 2 dome reversal pressure drifts down; SPC gave **5 days of early warning** before the first can fell below spec. Cpk dropped from 1.41 to 0.59 | X-bar/R chart, control limits from 60-day baseline, Rule 1 + 8-point run rule | Inspect bodymaker dome tooling for wear |

## Daily operations meeting pack

`outputs/daily_ops_report.xlsx` is regenerated on every run and contains:

| Sheet | Content |
|---|---|
| Daily KPI | Availability, performance, quality and OEE by line/shift/crew vs target, red/green formatting |
| Top Losses | Yesterday's stops by reason, minutes and estimated lost cans |
| SPC Status | Control limits, latest subgroup, Cpk and whether a signal fired in the last 3 shifts |
| Action Log (PDCA) | Open issues with owner, due date and next step |

## Methods

- **OEE** computed from summed quantities (not by averaging ratios) to avoid aggregation bias.
- **Pareto analysis** (80/20) to prioritise downtime reasons.
- **Non-parametric hypothesis testing** (Mann-Whitney U) because downtime minutes are skewed and zero-inflated.
- **SPC**: X-bar/R chart (n = 5), Phase I limits from a baseline window, Phase II monitoring with Rule 1 (point beyond limits) and an 8-in-a-row run rule.
- **Process capability**: one-sided Cpk against the lower spec limit.
